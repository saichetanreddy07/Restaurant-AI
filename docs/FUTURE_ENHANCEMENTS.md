# Future Enhancements

These are proposals, not implemented features or commitments.

## Short term — finish the current frontend

- Complete frontend polish, including adopting React Hook Form for shared forms where it simplifies validation and submission.
- Add focused frontend workflow tests and broaden backend regression coverage around inventory operations.
- Review keyboard navigation, form feedback, responsive layouts, and accessibility across operational modules.
- Add product screenshots and a short demo when a stable environment is available.

## Medium term — round out operations and delivery

- Build a guided production simulator that submits recipe consumption and presents batch deductions and results.
- Add a real Settings workflow once operational requirements are defined.
- Add inventory analytics such as waste trends, stock valuation, supplier spend, and cost of goods sold, supported by explicit API contracts.
- Prepare repeatable deployment and migration workflows, then host a demo.

## Long term — broader product capabilities

- Authentication and role-based permissions for kitchen staff, managers, and administrators.
- Demand forecasting based on historical consumption, after sufficient reliable data exists.
- Expiry-aware menu suggestions to help reduce waste, with human review.
- Adapt the generic inventory and operations model to retail, warehouse, manufacturing, pharmacy, or grocery workflows.
